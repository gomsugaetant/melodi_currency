# MELODI Devises & Taux de Change

Gestion des devises monétaires, symboles et taux de conversion de change.

## Informations du module

| Propriété | Valeur |
|---|---|
| Catégorie | finance |
| Version | 1.0.0 |

## Dépendances

- MELODI : `base`
- Python : aucune

## Installation dans MELODI

Dans une copie de MELODI, ajoutez ce dépôt comme sous-module à `modules/melodi_currency` :

```bash
git submodule add -f git@github.com:Byt3Lab/melodi_currency.git modules/melodi_currency
```

Si ce chemin contient déjà des fichiers, sauvegardez-les et déplacez-les avant d'ajouter le sous-module.
